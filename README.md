# Magic Shop MVP
Java 21 + Spring Boot + JdbcTemplate + PostgreSQL + HTML/CSS/JS. Без ORM и Spring Security.

Запуск: `docker compose up --build`

UI: http://localhost:8080/

Админ: admin@magic-shop.local / admin123
Пользователь: wizard@magic-shop.local / wizard123

Функционал: регистрация, вход, каталог, корзина, формирование заказа, история заказов, админ-управление товарами и статусами заказов.

Пароли хранятся открыто только для учебного MVP. В production это недопустимо.
